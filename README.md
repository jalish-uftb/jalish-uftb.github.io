## Built with

- Plain HTML, CSS and JavaScript, with no framework and no build step
- Google Fonts (Bricolage Grotesque and IBM Plex Sans)
- Responsive layout, automatic light and dark mode, and reduced-motion support
- Hosted free on [GitHub Pages](https://pages.github.com/)

## Run it on your computer

1. Download or clone this repository.
2. Double-click `index.html` to open it in your browser.

## Update the website

1. Open the file you want to change on GitHub (for example `index.html`).
2. Click the pencil icon to edit.
3. Click **Commit changes**.
4. Wait about a minute, then refresh the live site with Ctrl+F5.

Common edits:

| To change | Search for this in `index.html` |
|---|---|
| A project | `id="projects"` |
| Paper status (for example "Under review" to "Accepted") | `id="research"` |
| Skills | `id="skills"` |
| Colors | `:root{` near the top of the file |
| Profile photo | Replace `photo.jpg` with a new image of the same name |
| CV | Replace `CV_of_MD_JALISH_MAHAMUD.pdf` with a new file of the same name |

## Deployment

The site is deployed with **GitHub Pages** from the `main` branch, root folder. Every commit to `main` updates the live site automatically.
